The previous Hugo site is archived in the Git branch `archive/pre-redesign-2026-09-26` and tag `pre-redesign-2026-09-26`. A local copy is at `../juanpal-website-archived-2026-09-26/`, and a tar archive is at `../juanpal-website-before-redesign-2026-09-26.tar.gz`.
